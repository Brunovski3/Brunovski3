## ─ current experience

### DevOps & Cloud Intern · CCM Tecnologia

- Sustaining an **on-prem environment composed of 6 servers**, hosting internal applications and containerized services.
- Managing workloads running on **Docker**, with **Traefik** handling reverse proxy and internal/external routing.
- Managing and monitoring environments in **Oracle Cloud Infrastructure (OCI)**.
- Building and maintaining **CI/CD and GitOps workflows** using GitHub Actions and Komodo.
- **Leading the restructuring of 4 GitHub Organizations**, standardizing repositories, teams, permissions and access policies.
- Developing automation and integration workflows using **n8n, PostgreSQL, APIs and Shell scripts**.
- Building monitoring and observability solutions using **Grafana, Zabbix and Prometheus**.
- Developing and maintaining internal backend solutions using **Java / Spring Boot**.
- Working with internal networking, certificates and **PKI** for application infrastructure.
