## ─ what I do

**DevOps & Cloud Intern · CCM Tecnologia** · *Aug 2025 → present*

- 🐳 **Run 80+ containerized services** across a 6-server on-prem environment and OCI, with **Traefik** handling internal/external routing.
- ☁️ **Design OCI infrastructure** — compartments, networking and IAM — managed as code with **Terraform**.
- 🔐 **Implement SSO/OIDC with Authentik**, including JIT user provisioning and OAuth login for internal apps and Grafana.
- ⚙️ **Build CI/CD and GitOps pipelines** with GitHub Actions and Komodo.
- 🏛️ **Led the restructuring of 4 GitHub Organizations** — repositories, teams, permissions and access policies.
- 📊 **Own observability** with Grafana, Prometheus and Zabbix, from infra alerts to live operational dashboards.
- 🤖 **Automate internal operations** with n8n, PostgreSQL, Redis, APIs and Shell (onboarding flows, integrations, scheduled jobs).
- 🧩 **Support the Zoho platform** (CRM, Desk, Cliq) and internal IT operations.
- 🔑 Work with internal networking, certificates and **PKI**.
